## Strongest claim

> Weekweave is the weekly planner that refuses to let you overbook yourself. It combines tasks, time-block capacity, simple habits and a weekly review so you know what fits, what got done and what to improve next.

## Priorities for the working VibeFlow build

1. Make create-task → assign-to-block → save → refresh work.
2. Make an overcapacity assignment fail correctly and visibly.
3. Make complete-task and daily habit toggles persist.
4. Make the weekly reflection save and reopen.
5. Confirm layout and actions work on a phone and in another browser.
6. Replace all sample numbers with calculated results, or remove them.

## Suggested 60-second demo after functional implementation

- **0–10s:** Problem: “My to-do list kept making promises my calendar couldn't keep.” Show overview.
- **10–25s:** Create a 30-minute task, try assigning it to a block with only 24 minutes free. Show *real* capacity rejection.
- **25–39s:** Choose a block with enough capacity. Show the task and remaining capacity update.
- **39–49s:** Complete the task and mark a habit. Show real results change.
- **49–60s:** Save a weekly review; refresh and verify that data remains.

## November 4 positioning decision — use Path B, not a false cancellation claim

**Path:** **Unlock It**, because this project is the planning subscription the creator *would use*, not proof that a paid subscription was cancelled. **Comparator:** Sunsama at **$22/user/month**, billed monthly, verified from the official [Sunsama billing overview](https://help.sunsama.com/docs/billing/overview/) on November 4, 2026. $264/year is the *comparable spending rate*, not a claim of realized savings.

**Narrative:** "A to-do list doesn't know my work shifts. A calendar doesn't prevent me from overbooking tasks. I wanted the planning essentials of a premium daily planner, not another subscription." Use the actual differentiator: Busy vs Focus, capacity protection, completion releasing minutes, and evidence-based weekly reflection.

**Originality:** Weekweave has its own name, original visual identity, layout and interaction model. Do not imitate the paid comparator's UI or use its logo. Comparing the paid tool's basic purpose and public price is acceptable; claiming feature parity isn't.

**Prioritized live VibeFlow demo (45–60 seconds):**
1. Open a freshly created VibeFlow Weekweave project, not this GitHub Pages URL.
2. Show a 09:00–20:00 Busy work shift that adds zero task capacity.
3. Create a 120-minute Focus block, add a 90-minute task, and reject a second 40-minute task with a clear capacity explanation.
4. Complete the 90-minute task and show that minutes become available again.
5. Save a short weekly reflection, refresh, and show that it persisted.
6. Optionally show a Compass outcome with dated evidence, if genuinely functional.

**Judging check:** Covers a need; core interactions work live; a stranger can use it without instructions; the Slack entry clearly states paid tool, price, working feature and live VibeFlow URL. No cosmetic-only 'Save' buttons.

**Exclusions:** Never assert that Weekweave includes calendar integration, automatic notifications, team features, secure cloud storage, a full Sunsama replacement, or actual monthly savings.
