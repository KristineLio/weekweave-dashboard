# Hackathon submission plan — Weekweave

**Competition:** SkyCastle — Cancel My Subscription, November 4–7, 2026.  
**Suggested category:** $500 Most Useful Build.  
**Suggested path:** Unlock It (a premium planner you would like to use).  
**Subscription comparison:** Sunsama Pro, $22/month on monthly billing.  
**Submission deadline:** Saturday, November 7, 2026, 11:59 PM PST (**Sunday, November 8, 9:59 AM Sofia time**; PST is UTC−8 and Sofia is UTC+2).

## Strongest claim

> Weekweave is the weekly planner that refuses to let you overbook yourself. It combines tasks, time-block capacity, simple habits and a weekly review so you know what fits, what got done and what to improve next.

## Priorities for the working VibeFlow build

1. Make create-task → assign-to-block → save → refresh work.
2. Make an overcapacity assignment fail correctly and visibly.
3. Make complete-task and daily habit toggles persist.
4. Make the weekly reflection save and reopen.
5. Confirm layout and actions work on a phone and in another browser.
6. Replace all sample numbers with calculated results, or remove them.

## Suggested 60-second demo after functional implementation

- **0–10s:** Problem: “My to-do list kept making promises my calendar couldn't keep.” Show overview.
- **10–25s:** Create a 30-minute task, try assigning it to a block with only 24 minutes free. Show *real* capacity rejection.
- **25–39s:** Choose a block with enough capacity. Show the task and remaining capacity update.
- **39–49s:** Complete the task and mark a habit. Show real results change.
- **49–60s:** Save a weekly review; refresh and verify that data remains.
